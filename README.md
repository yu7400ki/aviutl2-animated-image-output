# AviUtl2 アニメーション画像出力プラグイン

AviUtl ExEdit2 で動画をアニメーション画像として出力できるプラグインセットです。

## 対応フォーマット

- **PNG** (APNG)
- **GIF**
- **WebP**
- **AVIF**

## 動作環境

- AviUtl ExEdit2 beta3 以降

## インストール

1. [Release](https://github.com/yu7400ki/aviutl2-animated-image-output/releases) から最新版のプラグインファイルをダウンロード
2. ダウンロードした auo2 ファイルを `%ProgramData%\aviutl2\Plugin` フォルダにコピー
   - 例: `C:\ProgramData\aviutl2\Plugin\apng_output.auo2`
3. AviUtl2 を再起動

## 使い方

1. AviUtl2 でプロジェクトを開く
2. メニューから「ファイル」→「ファイル出力」を選択
3. 出力したいフォーマットを選択（例: APNG 出力プラグイン）
4. 設定ダイアログで出力オプションを調整
5. 出力ファイル名を指定して保存

## 各フォーマットの特徴

### PNG (APNG)

- **特徴**: 高品質、可逆圧縮、大きなファイルサイズ
- **用途**: 高品質なアニメーション画像

### GIF

- **特徴**: 広く対応、256 色制限、半透明は残らない（全フレームを通した色の和集合が 256 色以内の素材は無劣化）
- **用途**: 互換性重視、軽量なアニメーション

### WebP

- **特徴**: 高圧縮率、可逆・非可逆両対応、半透明が残る（ロスレス圧縮なら入力と同じ画素で出力）
- **用途**: ウェブ用、ファイルサイズを抑えたい場合

### AVIF

- **特徴**: 最高の圧縮率、最新フォーマット、透過に対応
- **用途**: 最小ファイルサイズ、最新環境

## 設定項目

各プラグインには以下の設定項目があります：

### PNG（APNG）出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き
- **圧縮レベル**: 圧縮率と速度のトレードオフ（1-9、既定 6、値が大きいほど高圧縮）
- **色数を削減する**: 画素をパレット参照で書き出す（画素値は変わらない、既定 OFF）
  - 全フレームを通した色数が 256 色を超えると、**出力に失敗する**。この設定を OFF にすれば出力できる

### GIF 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き

### WebP 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き
- **ロスレス圧縮**: 入力と同じ画素で出力する（既定 OFF）
  - ON のときも品質・メソッドは有効。画素は変わらないまま、値を上げるほど時間がかかる。縮む量は素材次第で、2 割ほど縮むこともあれば、1 バイトも変わらないこともある。**最大値では数十倍の時間**がかかる
- **品質**: 画質（0-100）
- **メソッド**: 圧縮率と速度のトレードオフ（0-6、値が小さいほど高速）
- **ワーカー数**: 並列にエンコードする数（1 から論理 CPU 数まで。多いほどメモリ使用量が増える。時間が縮むのは大きい画面のロスレスなど 1 枚が重い場合で、出力結果は変わらない）

### AVIF 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **品質**: 画質設定（0-100）
- **エンコード速度**: エンコード速度（0-10、値が大きいほど高速。既定は 6）
  - **0-6** は圧縮を優先する動作点、**7-10** は配信向けの動作点で、同じ品質設定でもファイルサイズが大きく変わります
  - 既定値の変更は新しく設定を保存する場合にのみ適用されます。一度でも設定画面を開いたことがある場合は、これまでの値がそのまま使われます
- **カラーフォーマット**: 透過無し / 透過付き
- **YUV フォーマット**: 色空間設定（YUV420 / YUV422 / YUV444）

## 注意事項

- **処理時間について**: 圧縮設定や動画サイズによっては処理時間が極端に長くなる場合があります
- **ファイルサイズについて**: 動画に比べてファイルサイズが大きくなる傾向があります
