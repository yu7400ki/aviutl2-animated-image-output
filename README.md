# AviUtl2 アニメーション画像出力プラグイン

AviUtl ExEdit2 で動画をアニメーション画像として出力できるプラグインセットです。

## 対応フォーマット

- **PNG**（APNG）
- **GIF**
- **WebP**
- **AVIF**
- **JXL**

## 動作環境

- AviUtl ExEdit2 beta43a（2026/4/26）以降

## インストール

1. [Release](https://github.com/yu7400ki/aviutl2-animated-image-output/releases) から、全部入りか使いたい形式の zip をダウンロード
2. ダウンロードした zip を AviUtl2 のプレビュー画面にドラッグ&ドロップ
3. AviUtl2 を再起動

インストールしたパッケージは、AviUtl2 のパッケージ情報からアンインストールできます。

### 配布物

| ファイル名 | 中身 |
| --- | --- |
| `aviutl2-animated-image-output-v{version}.au2pkg.zip` | 全部入り（PNG / GIF / WebP / AVIF / JXL の 5 プラグイン） |
| `aviutl2-animated-image-output-png-v{version}.au2pkg.zip` | PNG（APNG）出力プラグイン |
| `aviutl2-animated-image-output-gif-v{version}.au2pkg.zip` | GIF 出力プラグイン |
| `aviutl2-animated-image-output-webp-v{version}.au2pkg.zip` | WebP 出力プラグイン |
| `aviutl2-animated-image-output-avif-v{version}.au2pkg.zip` | AVIF 出力プラグイン |
| `aviutl2-animated-image-output-jxl-v{version}.au2pkg.zip` | JXL 出力プラグイン |

## 使い方

1. AviUtl2 でプロジェクトを開く
2. メニューから「ファイル」→「ファイル出力」を選択
3. 出力したいフォーマットを選択
4. 設定ダイアログで出力オプションを調整
5. 出力ファイル名を指定して保存

## 各フォーマットの特徴

### PNG（APNG）

高品質、可逆圧縮

- **特徴**: 高品質なアニメーション画像、可逆圧縮
- **注意点**: 巨大なファイルサイズ

### GIF

広く対応、軽量

- **特徴**: 広い互換性、軽量なアニメーション
- **注意点**: 256 色制限、半透明非対応

### WebP

高圧縮率、可逆・非可逆両対応

- **特徴**: 高圧縮率、可逆・非可逆両対応

### AVIF

最高の圧縮率、最新フォーマット

- **特徴**: 最高の圧縮率、最小ファイルサイズ
- **注意点**: 低速なエンコード

### JXL

次世代フォーマット、可逆・非可逆両対応

- **特徴**: 高圧縮率、可逆・非可逆両対応
- **注意点**: 対応する環境が限られる

## 設定項目

各プラグインには以下の設定項目があります：

### PNG（APNG）出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き
- **圧縮レベル**: 圧縮率と速度のトレードオフ（1-9、既定 6、値が大きいほど高圧縮）
- **スレッド数**: 並列にエンコードする数（1 から論理 CPU 数まで、既定は論理 CPU 数の半分）

### GIF 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き

### WebP 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き
- **ロスレス圧縮**: 可逆圧縮の ON/OFF
- **品質**: 画質（0-100、既定 75）。ロスレス圧縮時はファイルサイズとのトレードオフ
- **メソッド**: 圧縮率と速度のトレードオフ（0-6、既定 4、値が小さいほど高速）
- **スレッド数**: 並列にエンコードする数（1 から論理 CPU 数まで、既定は論理 CPU 数の半分）

### AVIF 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **品質**: 画質設定（0-100）
- **エンコード速度**: エンコード速度（0-10、値が大きいほど高速）
- **カラーフォーマット**: 透過無し / 透過付き
- **YUV フォーマット**: 色空間設定（YUV420 / YUV422 / YUV444）
- **スレッド数**: 並列にエンコードする数（1 から論理 CPU 数まで、既定は論理 CPU 数の半分）

### JXL 出力設定

- **ループ回数**: アニメーションの繰り返し回数（0 = 無限ループ）
- **カラーフォーマット**: 透過無し / 透過付き
- **品質**: 画質（0-100、既定 90、100 で入力と同じ画素になる。透過付きの α は品質によらず可逆）
- **均衡**: 圧縮率と速度のトレードオフ（1-10、既定 7、値が大きいほど時間がかかる）
- **スレッド数**: 並列にエンコードする数（1 から論理 CPU 数まで、既定は論理 CPU 数の半分）

## 注意事項

- **ファイルサイズについて**: 動画に比べてファイルサイズが大きくなる傾向があります
- **パッケージの混在について**: 全部入りと形式ごとのパッケージは同じプラグインファイルをインストールします。両方を入れた状態で片方をアンインストールすると、もう片方が使うファイルも削除されます。どちらか一方だけを入れてください

## サードパーティライセンス
